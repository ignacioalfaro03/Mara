# MARA VERA — RITUALS + GUIDED EXPERIENCES V1

Status: content/product contract only. No produced audio, payment activation, deployment, provider activation, sexual-health claim, or spend is implied.

## 1. Product thesis

Mara should not sell only stories. She should create **repeatable private rituals** that users recognize, anticipate and return to.

The core distinction is:

- **RITUAL** = preparation, environment, symbols, posture, rules, timing, clothing, sensory anchors, voice, secrecy, callback.
- **GUIDED EXPERIENCE** = Mara leads the user through a bounded sequence of actions inside that ritual.

These are separate product primitives. A ritual can exist without a guided experience, and a guided experience can reference one or more rituals.

Commercial loop:

`RITUAL HOOK → PRIVATE SETUP → MARA RULE → GUIDED EXPERIENCE → MEMORABLE END → VAULT / CALLBACK → REPEAT RITUAL → NEXT EXPERIENCE`

The goal is habit through recognisable fiction and sensory cues, not infinite content volume.

## 3. Mara Ritual grammar

Every ritual should define:

1. **PLACE** — bedroom, bathroom at home, parked car, shower, mirror, bed, sofa, hotel room, late-night headphones, etc.
2. **SETUP** — door, light, headphones, clothing, object, scent, posture, silence.
3. **ANCHOR** — one repeatable sensory cue associated with Mara.
4. **RULE** — one simple instruction that gives the scene shape.
5. **VOICE MODE** — playful, direct, dominant, private, humiliating, intimate.
6. **BOUNDARY** — where the experience stops.
7. **CALLBACK** — phrase/object/action that can return in future DM/audio.
8. **VAULT MEMORY** — owned ritual or completed guided experience if entitled.

A ritual should be repeatable without becoming mechanically identical.

### G10 — CALLBACK

A later Mara message references the ritual anchor and offers a new scene/experience.
