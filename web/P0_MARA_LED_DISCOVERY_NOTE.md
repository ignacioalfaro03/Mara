# P0 Mara-Led Discovery Note

## Purpose

Extend the existing `/experience/segment-lab` without creating another lab.

Core hypothesis:

> **The user can steer. Mara should drive.**

The user should not need to configure the full experience or know the correct desire label before Mara can create relevance.

## Test comparisons

### A — Full configuration

Ask the tester to choose desire lane, modality, pace, control direction and payoff shape before Mara acts.

### B — Mara-led discovery

Mara makes one bounded prediction, chooses the first experience shape and then lets the tester react/correct.

Compare:
- perceived effort;
- perceived Mara intelligence;
- curiosity;
- character strength;
- correction comfort;
- continuation intent.

## Conversation leadership vs fantasy control

Conversation leadership defaults to Mara.

A specific fantasy can still be `mara_leads`, `user_leads` or `co_created`.

The product should not confuse those two variables.

Even when a fantasy is co-created, Mara frames the choices and moves the interaction forward.

## Pleasure timing fixture

D01 can include an abstract consent-gated anticipation / orgasm-delay-denial fixture.

This is not a new macro-lane and not a permanent identity label.

Test only the product idea:

`immediate payoff` vs `Mara delays the payoff / leaves tension open`.

Do not require explicit sexual instruction or real-world physical behavior in P0.

Measure:
- intrigue;
- perceived control/agency;
- willingness to continue;
- comfort with stop/skip;
- negative/pressured reaction;
- whether delayed payoff increases curiosity without feeling manipulative.

## Guardrails

- adults only;
- explicit compatible consent scope;
- stop/skip/reduce always available;
- no relationship punishment;
- no financial penalty;
- no surprise charge;
- no hidden higher price based on arousal/frustration;
- no permanent `denial` identity from one reaction;
- use synthetic/abstract fixtures.

## Decision

Keep Mara-led discovery if testers consistently report lower effort and higher perceived intelligence/character without increased pressure or correction friction.

Do not create another engine or another standalone product category merely because the denial/anticipation subdynamic performs well.
