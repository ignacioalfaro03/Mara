# Index note — Playable Rituals & Challenges

`playable-rituals-and-challenges.md` is the authoritative architecture for Mara's bounded games, rituals, dares and anticipation mechanics.

It extends Fantasy Compiler / Fantasy Experience Engine / Preference Graph / Desire Routing / Reward Grammar / Voice. It is not a new engine.

Key principles:
- Mara sometimes gives the user something to do, not only something to consume.
- Anticipation is a product mechanic.
- Adult ritual families require their own eligibility/consent.
- Failure changes the game, not the relationship.
- High-intensity rituals should be rare/contextual rather than constant.
- Arousal/compliance never becomes a hidden pricing or pressure variable.
