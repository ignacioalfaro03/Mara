## The repository-state test

A new production agent should be able to answer from this folder, without chat history:

- Which post is active?
- Which frame is next?
- What is Mara wearing?
- Which objects are locked?
- Where is the scene?
- What did the previous frame establish?
- Who is taking the next picture?
- How far has the food/drink/time state progressed?
- Which assets were rejected and why?
- Which facts are global canon vs scene-local?
- Which prompt-stack versions should generate the next frame?

If these cannot be answered, do not generate the next frame yet.
