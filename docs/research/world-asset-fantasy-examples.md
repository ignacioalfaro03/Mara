# World Asset Fantasy Examples — Research Notes

This file is a product/research note, not production content.

## Why this exists

Caprichos become more valuable if a funded asset can later be used as an active element in personalized experiences rather than only appearing as visual decoration.

Examples should remain bounded by adult consent, Preference Graph eligibility and provider/payment/platform rules.

## Product principle

The interesting effect is not merely `asset appears`.

It is:

> **the asset creates new things Mara can plausibly do later.**

That makes a funded World Asset a reusable narrative/fantasy primitive.

## Guardrails

- asset funding is not fetish consent;
- niche action is not inferred from one joke or one purchase;
- niche callbacks should be occasional/rare;
- no raw fetish values in generic analytics;
- a real asset can anchor a fictional generated action, but never fabricate physical provenance;
- contributor callback references shared history, not financial obligation or affection.
