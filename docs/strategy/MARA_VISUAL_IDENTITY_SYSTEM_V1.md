# MARA — VISUAL IDENTITY SYSTEM V1

Status: strategy draft for founder-led validation.  
Date: 2026-09-12.  
Authority: subordinate to `MARA_FOUNDATIONAL_THESIS.md` and complementary to `MARA_INSTAGRAM_FEED_SYSTEM_V1.md`.

## Objective

Build a visual system that becomes recognizable even when the Mara logo is absent.

The system must help Mara own these commercial memories:

- revenue leakage;
- the second sale;
- next best action;
- creator-customer memory;
- commercial evidence over guesswork.

The visual identity is not decoration. It is a memory system.

## Core identity direction

Working territory:

# COMMERCIAL EDITORIAL / DOCUMENTARY MODERNISM

Mara should feel like the intersection of:

- a serious business publication;
- a creator-economy field notebook;
- a revenue operator annotating real evidence;
- a software company with restraint.

Mara must not look like:

- a generic SaaS company;
- an AI startup;
- a marketing agency;
- a financial-services app;
- a motivational creator page;
- a templated Canva account.

## Distinctive asset system

The following assets should be deliberately repeated and protected over time.

### 1. Revenue Redline

A single deep-red line used to mark commercial attention.

Use cases:

- underline the missed moment;
- connect transaction to next action;
- mark a conversion break;
- circle one figure;
- show path from first to second purchase.

Rule:

> The redline must always mean something.

Never use it as random decoration.

### 2. Mara Margin Note

A small annotation written in the margin or attached to evidence.

Canonical labels:

- `REVENUE LEAK`
- `NEXT ACTION`
- `WHY THIS MATTERS`
- `PROOF`
- `OBSERVED`
- `HYPOTHESIS`
- `REPEAT READY`
- `MISSED SIGNAL`

The labels should be visually modest and repeated consistently.

### 3. Evidence Stamp

A compact evidence-status device.

Canonical values:

- `OBSERVED`
- `ATTRIBUTED`
- `HYPOTHESIS`
- `REAL ORDER`
- `REPEAT BUYER`
- `CREATOR REPORTED`

Purpose:

Make epistemic honesty visible.

Mara should visually distinguish fact from inference.

### 4. Second Sale Marker

Canonical device:

# `01 → 02`

Meaning:

- first purchase → second purchase;
- anonymous follower → known customer;
- transaction → relationship.

This is a candidate hero distinctive asset and should be tested repeatedly.

Possible variants:

- `01 / 02`
- `SALE 01 → SALE 02`
- `FIRST → SECOND`

Do not fragment this unnecessarily. `01 → 02` is the preferred initial device.

### 5. Revenue Number

One real commercial number may dominate the composition.

Examples:

- `$38.900`
- `42 DAYS`
- `6 BUYERS`
- `1 REPEAT PURCHASE`
- `17 ORDERS`
- `3 MISSED FOLLOW-UPS`

Numbers should come from real or clearly labeled hypothetical evidence.

### 6. Commercial Highlight Box

A thin, restrained frame used only around the highest-value decision.

Example:

`NEXT ACTION: Contact these 6 buyers before Friday.`

Do not use multiple boxes on one frame.

## Color system

### Core neutrals

Working palette:

- Paper: `#F2EEE7`
- Ink: `#111111`
- Warm Gray: `#A39B91`
- Soft Gray: `#D8D2CA`
- White: `#FFFFFF`

### Mara Red candidates

Candidate A — Oxblood:

- `#741F2B`
- character: editorial, serious, human, premium without luxury cosplay.

Candidate B — Ledger Red:

- `#8C2633`
- character: slightly more visible in mobile feeds, still restrained.

Candidate C — Signal Red:

- `#A3343D`
- character: strongest attention, higher risk of feeling promotional.

### Recommendation

Start testing with **Candidate A — `#741F2B`**.

Reason:

It is strong enough to become a memory cue while avoiding the bright-tech/startup look.

Do not use red as full-background default. Prefer red as a semantic signal against paper/ink.

Target usage:

- 70–80% neutral visual field;
- 5–15% Mara Red;
- remaining area photography/evidence.

## Typography system

The system needs two voices:

1. editorial authority;
2. operational clarity.

### Candidate typography system A — Recommended

Editorial / display:

- **Source Serif 4**

Operational / sans:

- **Inter**

Evidence / mono:

- **IBM Plex Mono**

Why this works:

- serious editorial contrast;
- excellent legibility on mobile;
- broad weight ranges;
- no fake futuristic AI feeling;
- practical for product/web/social consistency;
- open-source / operationally easy.

### Candidate typography system B — More distinctive editorial

Editorial / display:

- **DM Serif Display**

Operational / sans:

- **Manrope**

Evidence / mono:

- **IBM Plex Mono**

Character:

- stronger editorial personality;
- more expressive in campaign headlines;
- slightly higher risk of looking lifestyle/editorial rather than operator-led.

### Recommendation

Use **System A** as the baseline prototype.

Do not purchase proprietary typefaces yet. Prove the identity system first.

### Type hierarchy

Display headline:

- serif;
- 1–3 lines;
- generous leading;
- sentence case preferred;
- no forced all-caps except labels.

Operational label:

- sans;
- compact;
- medium/semibold;
- uppercase acceptable for evidence taxonomy.

Body / carousel explanation:

- sans;
- short measure;
- mobile-first size;
- never shrink text to fit too much information.

Evidence / timestamp:

- mono;
- used sparingly;
- only where data provenance or transactional character matters.

## Composition grammar

### Grid

Use an editorial grid, not a centered SaaS template.

Default:

- 12-column conceptual grid;
- generous left/right safe areas;
- intentional asymmetry allowed;
- one strong alignment axis per frame.

### Margins

Prefer generous negative space.

The feed should feel expensive because it is controlled, not because it is ornate.

### Headline placement

Preferred positions:

- upper-left editorial;
- lower-left over quiet photography;
- centered only for manifesto or number-led posts.

Avoid constant dead-center typography.

### Image crop

Prefer:

- close crops;
- hands / phones / work surfaces;
- portrait details;
- partial scenes that imply a larger business reality.

Avoid:

- over-wide generic office shots;
- obvious stock composition;
- staged laptop-smile photography.

## Photography treatment

### Desired qualities

- natural light when possible;
- real environments;
- muted saturation;
- realistic skin tones;
- visible material textures;
- slight grain acceptable;
- contrast controlled, not cinematic for its own sake;
- vertical composition planned at capture.

### Subject matter

Photograph:

- creators answering DMs;
- packaging orders;
- checking transaction history;
- filming content;
- writing pricing or launch notes;
- reviewing customer lists;
- working in bedroom/studio/gym/salon/kitchen contexts;
- screens with real workflows, privacy-safe;
- hands, tools, products, receipts, labels, notebooks;
- portraits after work, not staged productivity poses.

### Black and white

Use selectively for:

- Creator Business Portraits;
- founder/operator profiles;
- documentary moments;
- high-authority case-study covers.

Do not make the entire feed monochrome.

## Franchise visual signatures

### YOU ARE LOSING THIS SALE

Signature:

- documentary evidence;
- one Revenue Redline;
- one declarative headline;
- optional `REVENUE LEAK` margin note.

### THE SECOND SALE

Signature:

- `01 → 02` hero device;
- large whitespace;
- serif headline;
- buyer timeline / interval / repeat logic.

This should be the most distinctive franchise.

### REVENUE AUTOPSY

Signature:

- evidence-heavy composition;
- numbered annotations;
- diagnostic redlines;
- `OBSERVED` vs `HYPOTHESIS` stamps;
- clear final `NEXT ACTION` box.

### CREATOR BUSINESS NOTES

Signature:

- original documentary photography;
- small caption block;
- notebook/date/location treatment;
- restrained Mara branding.

### MARA FOUND IT

Signature:

- commercial situation first;
- actual/representative UI second;
- Revenue Number or highlighted customer segment;
- `NEXT ACTION` label.

### NO, YOU DO NOT NEED TO...

Signature:

- mostly typography;
- paper background;
- one crossed-out generic behavior in red;
- replacement action below in black.

## Reel art direction

### Opening frame

Must work muted.

Use one of:

- specific commercial sentence;
- real creator moment;
- number;
- transaction/DM evidence.

### Captions

- clean sans;
- maximum two lines at once;
- no bouncing word-by-word captions;
- red only for the commercial signal.

### Camera language

- handheld is acceptable when documentary;
- tripod for direct operator commentary;
- real sound encouraged;
- avoid overproduced ad transitions;
- cuts should follow evidence or argument, not trend templates.

## Story art direction

Stories are allowed to be more raw.

Keep:

- paper / black / Mara Red;
- redline annotation;
- consistent poll/question framing;
- screenshots annotated by hand-like digital marks.

Avoid turning Stories into a second polished feed.

## Logo rule

The logo is a signature, not the primary recognition system.

On most editorial posts:

- small;
- edge or corner placement;
- never competing with the idea.

Test:

> If the logo disappears, can the composition still plausibly be recognized as Mara?

If not, improve the asset system.

## Visual anti-patterns

Never normalize:

- gradient mesh backgrounds;
- AI-generated human creator portraits;
- 3D floating browser windows;
- abstract neon orbs;
- fake chat bubbles with invented testimonials;
- dozens of UI cards on one frame;
- excessive rounded rectangles;
- giant product-logo lockups on every post;
- emoji-led headline systems;
- colored backgrounds merely to make the grid alternate;
- template packs that visibly repeat another SaaS brand's grammar.

## Recognition test

Every 10–15 posts, run a founder review:

1. hide the account name and logo;
2. look at 9 random Mara posts mixed with 15 competitor posts;
3. ask whether Mara posts can be identified from:
   - Redline;
   - typography;
   - evidence treatment;
   - margin notes;
   - photography;
   - `01 → 02` device;
4. record false positives and false negatives;
5. simplify rather than add more assets.

## Asset priority

Do not try to make 20 things distinctive simultaneously.

Initial asset priority:

1. Revenue Redline;
2. `01 → 02`;
3. Mara Margin Note / Evidence Stamp;
4. paper + ink + oxblood palette;
5. documentary creator-business photography;
6. serif + sans editorial hierarchy.

Everything else is secondary.

## Final standard

Mara should not look visually innovative because it contains more effects.

Mara should look distinctive because it repeatedly uses a small number of meaningful devices better than everyone else.

The visual system should communicate:

> We looked at the evidence. We found the commercial signal. Here is the next move.
